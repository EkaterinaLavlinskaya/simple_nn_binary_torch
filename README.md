# simple_nn_binary_torch
Бинарная классификация с использованием нейросети на PyTorch

Задача: Разработать и обучить нейросеть для классификации объектов на два класса на основе синтетических данных (аналог задачи разделения клиентов или типов событий).

Что сделано:

Спроектирована и реализована на PyTorch полносвязная нейросеть (MLP) с архитектурой 2 → 4 → 1, использующая функции активации ReLU (для скрытого слоя) и Sigmoid (для выходного слоя).

Проведено обучение модели с оптимизатором Adam и функцией потерь BCELoss. Визуализирован процесс обучения (график снижения loss) и итоговое разделение классов.

Результаты:

Модель достигла 100% точности (accuracy 1.0) на тестовых данных, продемонстрировав идеальное разделение линейно неразделимых классов.

Проект наглядно показывает, как нейросети решают задачи, с которыми не справляются линейные модели, и служит основой для более сложных архитектур (например, для распознавания образов).

Стек: Python, PyTorch, scikit-learn (make_blobs), Matplotlib.
